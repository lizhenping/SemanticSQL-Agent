## 详细数据提取流程

```mermaid
flowchart TD
    Start([开始]) --> GetDbInfo[获取数据库信息]
    GetDbInfo --> GetTables[获取所有表名]
    GetTables --> FilterTables[过滤表名<br/>黑名单: aid_info]
    FilterTables --> LoopTables{遍历每个表}
    
    LoopTables --> ExtractTable[提取表元数据]
    ExtractTable --> GetTableComment[获取表注释<br/>可配置开关]
    GetTableComment --> GetColumns[获取列信息]
    GetColumns --> LoopColumns{遍历每列}
    
    LoopColumns --> ExtractColumn[提取列基础信息]
    ExtractColumn --> CheckFK[检查外键约束]
    CheckFK --> CalcEntropy[计算熵值等级<br/>采样500条]
    CalcEntropy --> CollectSample[采集样本值<br/>最多100个]
    CollectSample --> NextColumn{下一列?}
    
    NextColumn -->|是| LoopColumns
    NextColumn -->|否| NextTable{下一表?}
    NextTable -->|是| LoopTables
    NextTable -->|否| StoreNeo4j[存储到Neo4j]
    
    StoreNeo4j --> CreateDB[创建Database节点]
    CreateDB --> CreateTables[创建Table节点和关系]
    CreateTables --> CreateColumns[创建Column节点和关系]
    CreateColumns --> Success[返回成功消息]
    Success --> End([结束])
    
    %% 错误处理分支
    ExtractTable -->|失败| LogError[记录错误日志]
    CheckFK -->|失败| DefaultFK[设为null]
    CalcEntropy -->|失败| DefaultEntropy[设为low]
    CollectSample -->|失败| EmptySample[设为空数组]
    StoreNeo4j -->|失败| ErrorMsg[返回错误消息]
    
    LogError --> NextTable
    DefaultFK --> CalcEntropy
    DefaultEntropy --> CollectSample
    EmptySample --> NextColumn
    ErrorMsg --> End
    
    classDef process fill:#e3f2fd
    classDef decision fill:#fff3e0
    classDef error fill:#ffebee
    classDef success fill:#e8f5e8
    
    class GetDbInfo,ExtractTable,ExtractColumn,CheckFK,CalcEntropy,CollectSample,StoreNeo4j,CreateDB,CreateTables,CreateColumns process
    class LoopTables,LoopColumns,NextColumn,NextTable decision
    class LogError,DefaultFK,DefaultEntropy,EmptySample,ErrorMsg error
    class Success success
```

## 错误处理流程

```mermaid
flowchart TD
    Error[异常发生] --> CheckType{错误类型}
    
    CheckType -->|数据库连接| DbError[数据库错误]
    CheckType -->|Neo4j连接| Neo4jError[Neo4j错误]
    CheckType -->|业务逻辑| BusinessError[业务逻辑错误]
    
    DbError --> LogDbError[记录数据库错误日志]
    Neo4jError --> LogNeo4jError[记录Neo4j错误日志]
    BusinessError --> CheckSeverity{严重程度}
    
    CheckSeverity -->|关键| Critical[抛出异常]
    CheckSeverity -->|非关键| Warning[记录警告日志]
    
    LogDbError --> ReturnError[返回错误消息]
    LogNeo4jError --> ReturnError
    Critical --> ReturnError
    Warning --> UseDefault[使用默认值]
    
    UseDefault --> Continue[继续执行]
    ReturnError --> End[结束执行]
    Continue --> End
    
    classDef error fill:#ffebee
    classDef warning fill:#fff8e1
    classDef decision fill:#e8eaf6
    classDef action fill:#e8f5e8
    
    class Error,DbError,Neo4jError,BusinessError,Critical error
    class Warning,UseDefault warning
    class CheckType,CheckSeverity decision
    class LogDbError,LogNeo4jError,ReturnError,Continue,End action
```
