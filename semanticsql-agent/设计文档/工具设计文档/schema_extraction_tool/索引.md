## 🔧 快速参考

### 常用方法
```python
# 创建工具
tool = create_schema_extraction_tool(memory_manager, database_manager)

# 执行提取
result = tool._run()

# 自定义配置
tool = SchemaExtractionTool(
    memory_manager=memory_manager,
    database_manager=database_manager
)
```

### 配置项
- `table_blacklist`: 表过滤黑名单
- `entropy_sample_size`: 熵值计算采样数量（默认500）
- `sample_value_limit`: 样本值限制（默认100）
- `use_db_comments`: 是否使用数据库注释（默认true）

### 输出格式
- **成功**: `"✅ schema_extraction_tool提取完成，已存储到Neo4j。请继续执行field_analysis_tool工具。"`
- **失败**: `"❌ Schema提取失败: [错误详情]"`
