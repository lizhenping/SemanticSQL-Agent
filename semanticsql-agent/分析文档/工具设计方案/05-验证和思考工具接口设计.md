## 7. 工具使用模式

### 7.1 验证工具链
```
sql_generation 完成
    ↓
sql_validation (自动验证生成的SQL)
    ↓
sql_execution (执行验证通过的SQL)
```

### 7.2 思考工具使用
```
任何阶段都可以调用 sequential_thinking：
- 分析阶段后：思考分析是否完整
- 生成阶段后：思考生成质量如何
- 验证阶段后：思考整体结果是否满意
```

## 8. 工具特殊设计考虑

### 8.1 SQL执行安全措施
- 只允许SELECT查询
- 限制返回行数（如100行）
- 设置执行超时时间
- 使用只读数据库连接

### 8.2 思考工具触发机制
- 可以在任何阶段被LLM主动调用
- 特别适合在复杂任务或遇到问题时使用
- 作为质量检查和改进建议的工具

---

**设计特点**：
1. **安全优先**：验证和执行工具都有严格的安全限制
2. **状态感知**：工具从memory获取上下文，无需外部参数
3. **灵活调用**：思考工具可在任何阶段被LLM调用
4. **专用结构**：验证和思考工具有各自的专用数据结构
5. **链式依赖**：验证→执行的自然流程
