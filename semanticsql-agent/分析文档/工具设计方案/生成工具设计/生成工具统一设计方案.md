# 生成工具统一设计方案

## 1. 工具概览

### 1.1 生成工具清单
- **scenario_operation_tool**: 场景操作生成
- **question_generation_tool**: 问题生成
- **sql_generation_tool**: SQL查询生成

### 1.2 设计目标
- **分析驱动**: 基于分析阶段的所有三元组进行智能生成
- **上下文感知**: 充分利用数据库结构、领域信息、语义分析等上下文
- **质量保证**: 生成结果符合实际数据库结构和业务逻辑

## 2. 统一接口设计

### 2.1 基础接口
```python
class BaseGenerationTool(BaseSemanticSQLTool):
    def _run(self, **params) -> TripleCollection:
        # 第1步：获取所有分析阶段的三元组上下文
        analysis_context = self._get_analysis_context()
        
        # 第2步：基于上下文执行生成逻辑
        generation_result = self._generate_with_context(params, analysis_context)
        
        # 第3步：输出三元组集合
        output_triples = self._format_generation_triples(generation_result)
        self.memory.save_triples(self.name, output_triples)
        return output_triples
```

### 2.2 输入参数（按工具不同）
```python
# scenario_operation_tool
{"domain": "e_commerce", "complexity": "medium"}

# question_generation_tool  
{"scenario_info": {...}, "question_count": 5}

# sql_generation_tool
{"question": "查询销售额前10的用户"}
```

### 2.3 输出格式
```python
# 统一的三元组输出格式
output = TripleCollection()

# scenario_operation -> ("e_commerce", "has_scenario", "用户购买行为分析")
# question_generation -> ("scenario_1", "generates_question", "哪些用户购买金额最高？")
# sql_generation -> ("question_1", "generates_sql", "SELECT user_id, SUM(amount) FROM orders...")
```

## 3. 各工具设计要点

### 3.1 Scenario Operation Tool
**职责**: 基于领域信息生成业务场景和操作类型

#### 输入依赖
```python
# 从analysis阶段获取的三元组：
- domain_analysis: 业务领域归属
- table_analysis: 表的业务逻辑
- er_analysis: 实体关系信息
```

#### 输出三元组示例
```python
("e_commerce", "has_scenario", "用户购买行为分析")
("user_analysis", "operation_type", "aggregation")
("sales_analysis", "operation_type", "statistical") 
("user_behavior", "complexity_level", "medium")
("scenario_1", "involves_tables", ["users", "orders", "products"])
```

#### 生成策略
- **领域驱动**: 根据识别的业务领域生成相关场景
- **表关系驱动**: 基于实体关系生成合理的业务操作
- **复杂度分级**: 生成不同复杂度的场景供后续使用

### 3.2 Question Generation Tool
**职责**: 基于场景信息生成自然语言问题

#### 输入依赖
```python
# 主要输入：scenario_operation的结果
# 辅助上下文：所有analysis阶段的三元组
- schema_extraction: 了解可查询的数据结构
- column_analysis: 了解字段的业务含义
- scenario_operation: 获取场景和操作类型
```

#### 输出三元组示例
```python
("scenario_user_analysis", "generates_question", "哪些用户的购买金额最高？")
("scenario_sales_trend", "generates_question", "最近一个月的销售趋势如何？")
("question_1", "question_type", "ranking")
("question_2", "question_type", "trend_analysis")
("question_1", "involves_columns", ["user_id", "order_amount"])
```

#### 生成策略
- **模板驱动**: 基于场景类型使用问题模板
- **字段感知**: 根据可用字段生成切实可行的问题
- **多样性保证**: 生成不同类型和复杂度的问题

### 3.3 SQL Generation Tool
**职责**: 基于自然语言问题生成SQL查询

#### 输入依赖
```python
# 主要输入：自然语言问题
# 全量上下文：所有前序阶段的三元组
- schema_extraction: 数据库结构信息
- field_analysis: 字段语义类型
- column_analysis: 字段业务含义
- er_analysis: 表间关系
- question_generation: 问题上下文（如果有）
```

#### 输出三元组示例
```python
("问题1", "generates_sql", "SELECT u.name, SUM(o.amount) FROM users u JOIN orders o ON u.id = o.user_id GROUP BY u.id ORDER BY SUM(o.amount) DESC LIMIT 10;")
("sql_1", "query_type", "aggregation_with_join")
("sql_1", "uses_tables", ["users", "orders"])
("sql_1", "uses_operations", ["JOIN", "GROUP BY", "ORDER BY", "LIMIT"])
("sql_1", "complexity_score", 0.7)
```

#### 生成策略
- **结构感知**: 严格基于实际数据库结构生成SQL
- **语义映射**: 将自然语言映射到具体的字段和操作
- **关系利用**: 充分利用ER分析的表间关系信息
- **优化考虑**: 生成高效的查询语句

## 4. 执行顺序和依赖

### 4.1 推荐执行顺序
```
1. scenario_operation    (依赖: 所有analysis结果)
2. question_generation   (依赖: scenario_operation + analysis结果)  
3. sql_generation       (依赖: 所有前序结果 + 输入问题)
```

### 4.2 灵活调用模式
```python
# 完整流程
scenario -> question -> sql

# 直接问题到SQL
question -> sql (跳过scenario和question_generation)

# 批量生成
scenario -> multiple_questions -> multiple_sqls
```

## 5. 调用示例

### 5.1 智能体动态调用
```python
# 智能体根据任务需求动态调用生成工具
result = agent.execute_workflow(task="基于数据库生成SQL查询")
```

## 6. 增强策略

### 6.1 思考增强触发条件
- **生成结果过少**: 生成的问题/SQL数量 < 预期
- **质量不确定**: 生成结果的confidence score < 0.8
- **复杂任务**: 涉及多表关联、复杂聚合操作
- **上下文丰富**: 有大量分析上下文可利用

### 6.2 增强效果
- **质量提升**: 生成更准确、更符合业务逻辑的结果
- **多样性增加**: 利用全量上下文生成更多样化的问题和SQL
- **一致性保证**: 确保生成结果与数据库结构完全一致

## 7. 实施要点

### 7.1 开发优先级
1. **sql_generation**: 核心功能，优先实现
2. **question_generation**: 为测试和演示提供问题
3. **scenario_operation**: 为批量生成提供场景支持

### 7.2 技术关键点
- **模板系统**: 支持不同领域和场景的问题/SQL模板
- **语义解析**: 自然语言到SQL的准确映射
- **结果验证**: 生成结果的语法和逻辑验证
- **性能优化**: 批量生成时的效率优化

### 7.3 质量保证
- **结构验证**: 确保生成的SQL符合数据库结构
- **语法检查**: SQL语法正确性验证
- **逻辑一致**: 问题与SQL的逻辑一致性检查
- **可执行性**: 生成的SQL可以在目标数据库上执行
