# 系统提示词使用总结

## 当前状态

### 实际使用的提示词
- **主要使用**: `system/main_flexible.j2` 
- **备选**: `system/main.j2`
- **未使用**: `system/agent_system.j2`

### 选择逻辑（在 base_agent.py 中）
```python
1. 首先尝试加载 main_flexible.j2
2. 如果失败，尝试加载 main.j2  
3. 如果都失败，使用硬编码的默认提示词
```

## 已完成的优化

### main_flexible.j2 的修改
1. **数据库分析部分**：
   - 从"可以使用"改为"**必须**先充分理解数据库"
   - 明确列出6个分析步骤的执行顺序
   - 强调"不能跳过"

2. **训练数据生成部分**：
   - 从"考虑以下流程"改为"**必须按顺序执行以下7个步骤**"
   - 详细说明每个步骤的输入输出
   - 强调"不能跳过任何步骤"

## 三个提示词的定位

1. **main_flexible.j2**（主用）
   - 平衡了灵活性和结构化
   - 适合智能Agent，给予一定自主权
   - 经过优化后，关键步骤已强制执行

2. **main.j2**（备用）
   - 更加结构化和严格
   - 适合需要严格流程控制的场景
   - 可作为main_flexible失败时的后备

3. **agent_system.j2**（未使用）
   - 最详细和严格的版本
   - 包含执行示例
   - 可考虑在特定场景下使用

## 效果

经过优化后，main_flexible.j2 现在：
- ✅ 强制执行数据库分析（6个步骤）
- ✅ 强制执行完整的生成流程（7个步骤）
- ✅ 保持了一定的灵活性（在如何执行上）
- ✅ 明确了每个工具的输入输出

这样既保证了流程的完整性，又不会过于僵化。
