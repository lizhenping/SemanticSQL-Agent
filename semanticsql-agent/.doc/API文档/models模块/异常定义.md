定义系统中使用的所有自定义异常类。

> 文件位置：`models/exceptions.py`

## 基础异常类

### SemanticSQLException

```python
class SemanticSQLException(Exception):
    """
    SemanticSQL Agent 基础异常类
    
    所有自定义异常都继承自此类。
    
    Attributes:
        message: 错误信息
        error_code: 错误代码（可选）
        details: 详细信息（可选）
    """
    
    def __init__(self, message: str, error_code: str = None, details: Dict[str, Any] = None):
        super().__init__(message)
        self.message = message
        self.error_code = error_code
        self.details = details or {}
```

## 数据库相关异常

### DatabaseError

```python
class DatabaseError(SemanticSQLException):
    """数据库操作错误基类"""
    pass

class DatabaseConnectionError(DatabaseError):
    """数据库连接错误"""
    def __init__(self, host: str, database: str, original_error: Exception):
        super().__init__(
            f"Failed to connect to database {database} at {host}",
            error_code="DB_001",
            details={"host": host, "database": database, "error": str(original_error)}
        )

class SQLExecutionError(DatabaseError):
    """SQL 执行错误"""
    def __init__(self, sql: str, error: str):
        super().__init__(
            f"SQL execution failed: {error}",
            error_code="DB_002",
            details={"sql": sql, "error": error}
        )

class SchemaExtractionError(DatabaseError):
    """Schema 提取错误"""
    def __init__(self, table_name: str = None, error: str = None):
        message = "Failed to extract schema"
        if table_name:
            message += f" for table {table_name}"
        if error:
            message += f": {error}"
        super().__init__(message, error_code="DB_003")
```

## 验证相关异常

### ValidationError

```python
class ValidationError(SemanticSQLException):
    """验证错误基类"""
    pass

class SQLValidationError(ValidationError):
    """SQL 语法验证错误"""
    def __init__(self, sql: str, errors: List[str]):
        super().__init__(
            f"SQL validation failed: {', '.join(errors)}",
            error_code="VAL_001",
            details={"sql": sql, "errors": errors}
        )

class DataValidationError(ValidationError):
    """数据验证错误"""
    def __init__(self, field: str, value: Any, rule: str):
        super().__init__(
            f"Data validation failed for field '{field}': {rule}",
            error_code="VAL_002",
            details={"field": field, "value": value, "rule": rule}
        )
```

## 使用示例

### 抛出异常

```python
from semanticsql_agent.models.exceptions import (
    DatabaseConnectionError,
    SQLExecutionError,
    ToolExecutionError
)

# 数据库连接失败
try:
    connection = connect_to_database(config)
except Exception as e:
    raise DatabaseConnectionError(
        host=config.host,
        database=config.database,
        original_error=e
    )

# SQL 执行失败
try:
    result = execute_sql(sql)
except Exception as e:
    raise SQLExecutionError(sql=sql, error=str(e))

# 工具执行失败
try:
    result = tool.run(**params)
except Exception as e:
    raise ToolExecutionError(
        tool_name=tool.name,
        reason=str(e)
    )
```

### 捕获和处理异常

```python
from semanticsql_agent.models.exceptions import (
    SemanticSQLException,
    DatabaseError,
    LLMError
)

try:
    result = agent.generate_questions(count=100)
except DatabaseError as e:
    # 处理数据库相关错误
    logger.error(f"Database error: {e.message}")
    logger.debug(f"Details: {e.details}")
    # 可能需要重新连接或回滚
except LLMError as e:
    # 处理 LLM 相关错误
    logger.error(f"LLM error: {e.message}")
    # 可能需要重试或使用备用模型
except SemanticSQLException as e:
    # 处理其他已知错误
    logger.error(f"Error: {e.message} (Code: {e.error_code})")
except Exception as e:
    # 处理未预期的错误
    logger.critical(f"Unexpected error: {e}", exc_info=True)
```

### 错误处理装饰器

```python
from functools import wraps
from semanticsql_agent.models.exceptions import ToolExecutionError

def handle_tool_errors(func):
    """工具错误处理装饰器"""
    @wraps(func)
    def wrapper(self, *args, **kwargs):
        try:
            return func(self, *args, **kwargs)
        except Exception as e:
            raise ToolExecutionError(
                tool_name=self.name,
                reason=str(e)
            ) from e
    return wrapper

class MyTool(BaseTool):
    name = "my_tool"
    
    @handle_tool_errors
    def _run(self, **kwargs):
        # 工具逻辑
        pass
```

## 错误代码规范

| 前缀 | 类型 | 示例 |
|------|------|------|
| CONFIG_ | 配置错误 | CONFIG_001: 缺少配置 |
| DB_ | 数据库错误 | DB_001: 连接失败 |
| LLM_ | LLM 错误 | LLM_001: API 连接失败 |
| TOOL_ | 工具错误 | TOOL_001: 执行失败 |
| AGENT_ | Agent 错误 | AGENT_001: 执行失败 |
| VAL_ | 验证错误 | VAL_001: SQL 验证失败 |

## 注意事项

1. **始终使用具体的异常类**：避免直接抛出 `Exception`
2. **提供有用的错误信息**：包含上下文和可能的解决方案
3. **使用错误代码**：便于日志分析和监控
4. **保留原始异常**：使用 `from e` 保留调用栈
5. **记录详细信息**：在 `details` 中包含调试所需的信息
