# 数据格式规范

本文档定义 SemanticSQL Agent 生成的训练数据格式。

## 输出文件格式

系统支持两种输出格式：

### 1. JSONL 格式（推荐）

每行一个 JSON 对象，便于流式处理和增量写入。

```jsonl
{"id": "q_001", "scenario": "销售分析", "question": "查询2024年1月的销售总额", "sql": "SELECT SUM(total_amount) FROM orders WHERE DATE_FORMAT(order_date, '%Y-%m') = '2024-01'", "difficulty": "easy", "operations": ["SELECT", "AGGREGATE", "WHERE", "DATE_FUNCTION"], "tables": ["orders"], "timestamp": "2024-01-15T10:30:00", "validation": {"syntax_valid": true, "execution_success": true, "row_count": 1, "execution_time": 0.023}}
{"id": "q_002", "scenario": "库存查询", "question": "列出库存不足10件的产品", "sql": "SELECT product_id, product_name, stock_quantity FROM products WHERE stock_quantity < 10", "difficulty": "easy", "operations": ["SELECT", "WHERE"], "tables": ["products"], "timestamp": "2024-01-15T10:30:01", "validation": {"syntax_valid": true, "execution_success": true, "row_count": 15, "execution_time": 0.015}}
```

### 2. JSON 格式

标准 JSON 数组格式，包含所有生成的数据。

```json
{
  "metadata": {
    "version": "1.0",
    "generator": "SemanticSQL Agent",
    "timestamp": "2024-01-15T10:30:00",
    "database": "ecommerce",
    "total_count": 100,
    "success_count": 95,
    "failed_count": 5
  },
  "data": [
    {
      "id": "q_001",
      "scenario": {
        "id": "scenario_sales_001",
        "category": "销售分析",
        "business_purpose": "分析销售趋势",
        "difficulty": "medium"
      },
      "question": "查询2024年1月的销售总额",
      "sql": "SELECT SUM(total_amount) FROM orders WHERE DATE_FORMAT(order_date, '%Y-%m') = '2024-01'",
      "operations": ["SELECT", "AGGREGATE", "WHERE", "DATE_FUNCTION"],
      "tables": ["orders"],
      "timestamp": "2024-01-15T10:30:00",
      "validation": {
        "syntax_valid": true,
        "execution_success": true,
        "row_count": 1,
        "execution_time": 0.023,
        "result_sample": [{"total_sales": 125000.50}]
      },
      "quality_score": 0.95
    },
    // ... 更多数据
  ]
}
```

## 数据字段说明

### 必需字段

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | string | 唯一标识符 |
| question | string | 自然语言问题 |
| sql | string | 生成的 SQL 查询 |
| timestamp | string | 生成时间（ISO 8601） |

### 场景信息

| 字段 | 类型 | 说明 |
|-----|------|------|
| scenario | object/string | 场景信息（JSONL中为名称，JSON中为对象） |
| scenario.category | string | 场景类别 |
| scenario.business_purpose | string | 业务目的 |
| difficulty | string | 难度等级：easy/medium/hard/expert |

### SQL 元信息

| 字段 | 类型 | 说明 |
|-----|------|------|
| operations | array | 使用的 SQL 操作列表 |
| tables | array | 涉及的表名列表 |
| has_join | boolean | 是否包含 JOIN |
| has_aggregation | boolean | 是否包含聚合 |

### 验证信息

| 字段 | 类型 | 说明 |
|-----|------|------|
| validation | object | 验证结果 |
| validation.syntax_valid | boolean | SQL 语法是否正确 |
| validation.execution_success | boolean | 执行是否成功 |
| validation.row_count | integer | 返回行数 |
| validation.execution_time | float | 执行时间（秒） |
| validation.error | string | 错误信息（如果有） |

### 质量信息

| 字段 | 类型 | 说明 |
|-----|------|------|
| quality_score | float | 质量评分 (0-1) |
| reflection_result | object | 反思结果（可选） |

## 使用示例

### 读取 JSONL 文件

```python
import json

def read_jsonl(file_path):
    """读取 JSONL 格式的训练数据"""
    data = []
    with open(file_path, 'r', encoding='utf-8') as f:
        for line in f:
            if line.strip():
                data.append(json.loads(line))
    return data

# 使用示例
training_data = read_jsonl("training_data.jsonl")
print(f"加载了 {len(training_data)} 条训练数据")
```

### 读取 JSON 文件

```python
import json

def read_json(file_path):
    """读取 JSON 格式的训练数据"""
    with open(file_path, 'r', encoding='utf-8') as f:
        data = json.load(f)
    return data['data']  # 返回数据数组

# 使用示例
data = read_json("training_data.json")
print(f"加载了 {len(data)} 条训练数据")
```

### 数据验证

```python
def validate_training_data(data_item):
    """验证单条训练数据的完整性"""
    required_fields = ['id', 'question', 'sql', 'timestamp']
    
    for field in required_fields:
        if field not in data_item:
            return False, f"缺少必需字段: {field}"
    
    if not data_item['question'].strip():
        return False, "问题不能为空"
    
    if not data_item['sql'].strip():
        return False, "SQL 不能为空"
    
    return True, "验证通过"
```

## 数据质量标准

### 高质量数据特征

1. **问题清晰**：自然语言描述准确、无歧义
2. **SQL 正确**：语法正确、逻辑合理、性能良好
3. **匹配度高**：SQL 准确实现问题意图
4. **可执行性**：在目标数据库上可成功执行

### 质量评分标准

- **0.9-1.0**：优秀，可直接用于训练
- **0.7-0.9**：良好，轻微问题
- **0.5-0.7**：一般，需要审核
- **< 0.5**：差，建议重新生成

## 数据后处理

### 数据清洗

```python
def clean_training_data(data):
    """清洗训练数据"""
    cleaned = []
    for item in data:
        # 过滤低质量数据
        if item.get('quality_score', 0) < 0.7:
            continue
        
        # 过滤执行失败的数据
        if not item.get('validation', {}).get('execution_success'):
            continue
        
        cleaned.append(item)
    
    return cleaned
```

### 数据统计

```python
def analyze_training_data(data):
    """统计训练数据"""
    stats = {
        'total': len(data),
        'by_difficulty': {},
        'by_scenario': {},
        'avg_quality': 0
    }
    
    for item in data:
        # 难度分布
        difficulty = item.get('difficulty', 'unknown')
        stats['by_difficulty'][difficulty] = stats['by_difficulty'].get(difficulty, 0) + 1
        
        # 场景分布
        scenario = item.get('scenario', 'unknown')
        if isinstance(scenario, dict):
            scenario = scenario.get('category', 'unknown')
        stats['by_scenario'][scenario] = stats['by_scenario'].get(scenario, 0) + 1
        
        # 平均质量
        stats['avg_quality'] += item.get('quality_score', 0)
    
    stats['avg_quality'] /= len(data) if data else 1
    
    return stats
```

## 注意事项

1. **编码**：始终使用 UTF-8 编码
2. **大小限制**：单个文件建议不超过 1GB
3. **增量生成**：使用 JSONL 格式便于增量追加
4. **备份**：定期备份生成的训练数据
5. **隐私**：确保不包含敏感数据
