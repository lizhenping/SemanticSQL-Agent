## 异常使用一致性

### ✅ 导入路径统一
所有异常都从 `semanticsql_agent.models.exceptions` 导入：
```python
from semanticsql_agent.models.exceptions import (
    ToolExecutionError,
    DatabaseConnectionError,
    LLMError,
    # ...
)
```

### ✅ 异常构造函数使用正确
所有异常都使用了正确的参数格式：
```python
# 正确
raise ToolExecutionError(
    tool_name=self.name,
    reason="Error message"
)

# 正确
raise DatabaseConnectionError(
    host=config.host,
    database=config.database,
    original_error=e
)
```

### ✅ 错误代码规范
遵循了统一的错误代码前缀：
- CONFIG_xxx: 配置错误
- DB_xxx: 数据库错误
- LLM_xxx: LLM错误
- TOOL_xxx: 工具错误
- AGENT_xxx: Agent错误
- VAL_xxx: 验证错误
