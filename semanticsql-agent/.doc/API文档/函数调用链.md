## 2. 数据库分析阶段

### 2.1 分析工具调用链

```python
# Agent 内部执行 _analyze_database()
def _analyze_database(self):
    # 1. 结构提取
    schema_result = extract_schema_tool.run({
        "database_name": self.db_config.database
    })
    self.memory.update_analysis("schema_info", schema_result)
    
    # 2. 领域分析
    domain_result = domain_analysis_tool.run({
        "memory": self.memory.load_memory_variables({})
    })
    self.memory.update_analysis("domain_analysis", domain_result)
    
    # 3. 字段分类
    field_result = field_classification_tool.run({
        "memory": self.memory.load_memory_variables({})
    })
    self.memory.update_analysis("field_classification", field_result)
    
    # 4. 列含义分析
    column_result = column_meaning_tool.run({
        "memory": self.memory.load_memory_variables({})
    })
    self.memory.update_analysis("column_meanings", column_result)
    
    # 5. 表含义分析
    table_result = table_meaning_tool.run({
        "memory": self.memory.load_memory_variables({})
    })
    self.memory.update_analysis("table_meanings", table_result)
    
    # 6. 关系分析
    er_result = er_analysis_tool.run({
        "memory": self.memory.load_memory_variables({})
    })
    self.memory.update_analysis("er_analysis", er_result)
```

## 3. 问题生成循环

### 3.1 主循环流程

```python
def generate_questions(self, count: int, output_file: str):
    results = []
    
    for i in range(count):
        # 获取当前记忆状态
        current_memory = self.memory.load_memory_variables({})
        
        # 1. 选择场景
        scenario = scenario_tool.run({
            "memory": current_memory,
            "iteration": i
        })
        
        # 2. 选择操作
        operations = operation_selection_tool.run({
            "scenario": scenario,
            "memory": current_memory
        })
        
        # 3. 生成问题
        question_result = question_generation_tool.run({
            "scenario": scenario,
            "operations": operations,
            "memory": current_memory
        })
        
        # 4. 生成 SQL
        sql_result = sql_generation_tool.run({
            "question": question_result["question"],
            "memory": current_memory
        })
        
        # 5. 验证 SQL
        validation_result = sql_validation_tool.run({
            "sql": sql_result["sql"],
            "memory": current_memory
        })
        
        # 6. 执行 SQL（如果验证通过）
        if validation_result["valid"]:
            execution_result = sql_execution_tool.run({
                "sql": sql_result["sql"]
            })
        else:
            execution_result = {"success": False, "error": "Validation failed"}
        
        # 7. 反思评估
        reflection_result = sql_reflection_tool.run({
            "sql": sql_result["sql"],
            "execution_result": execution_result,
            "question": question_result["question"],
            "scenario": scenario,
            "operations": operations,
            "memory_usage": current_memory
        })
        
        # 8. 处理反思结果
        if reflection_result["needs_revision"]:
            self._handle_revision(reflection_result, context)
        else:
            results.append({
                "scenario": scenario,
                "question": question_result["question"],
                "sql": sql_result["sql"],
                "execution": execution_result
            })
```

### 3.2 修正处理流程

```python
def _handle_revision(self, reflection_result, context):
    # Agent 自主决定是否需要深度思考
    if reflection_result["quality_score"] < 0.5 or len(reflection_result["issues"]) > 2:
        # 调用深度思考工具
        thinking_result = sequential_thinking_tool.run({
            "problem": reflection_result["issues"],
            "context": context
        })
        
        # 根据思考结果执行修正
        self._execute_fix_strategy(thinking_result["fix_strategy"])
    else:
        # 直接使用反思工具的建议
        recommended_tool = reflection_result["recommended_action"]["tool_to_call"]
        if recommended_tool:
            self._call_tool(recommended_tool, context)
```

## 4. 工具参数规范

### 4.1 分析工具

所有分析工具（除 schema_extraction）都接收 memory 参数：
```python
# 正确 ✓
tool.run({"memory": memory})

# 错误 ✗
tool.run({"schema_info": schema_info})
```

### 4.2 生成工具

生成工具统一使用 memory：
```python
# scenario_tool
{"memory": memory, "iteration": i}

# operation_selection_tool
{"scenario": scenario, "memory": memory}

# question_generation_tool
{"scenario": scenario, "operations": operations, "memory": memory}

# sql_generation_tool
{"question": question, "memory": memory}
```

### 4.3 验证工具

```python
# sql_validation_tool
{"sql": sql, "memory": memory}

# sql_execution_tool
{"sql": sql}  # 不需要 memory
```

### 4.4 反思和思考工具

```python
# sql_reflection_tool
{
    "sql": sql,
    "execution_result": result,
    "question": question,
    "scenario": scenario,
    "operations": operations,
    "memory_usage": memory
}

# sequential_thinking_tool
{
    "problem": issues,
    "context": full_context
}
```

## 5. 关键设计要点

### 5.1 记忆传递原则

1. **统一使用 memory 参数**：避免传递单独的 schema_info、domain_info 等
2. **记忆是动态的**：可以通过 update_analysis 更新
3. **工具从记忆中提取所需信息**：如 `memory["db_analysis"]["schema_info"]`

### 5.2 错误处理链

```python
try:
    result = tool.run(params)
except ToolExecutionError as e:
    # 工具级错误
    logger.error(f"Tool {tool.name} failed: {e}")
    # Agent 决定是否重试或跳过
except Exception as e:
    # 未预期错误
    raise AgentExecutionError(f"Unexpected error in {tool.name}: {e}")
```

### 5.3 Agent 自主决策

Agent 根据反思结果自主决定：
1. 是否需要修正
2. 是否调用 sequential_thinking
3. 调用哪个工具进行修正

### 5.4 不可修改的内容

- `scenario_tool` 的结果（预定义模板）
- `operation_selection` 的结果（预定义规则）

### 5.5 可修正的内容

- 数据库分析结果（通过重新执行分析工具）
- 问题生成结果
- SQL 生成结果

## 6. 完整性检查

✅ **数据库分析阶段**：6个工具按顺序执行，结果保存在记忆中
✅ **生成循环**：for 循环，每次生成一个问题
✅ **记忆传递**：统一使用 memory 参数
✅ **反思机制**：包含问题定位和工具推荐
✅ **自主决策**：Agent 根据反思结果决定后续动作
✅ **错误处理**：完整的异常处理链
