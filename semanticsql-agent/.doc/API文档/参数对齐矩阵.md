# 参数对齐矩阵

本文档展示所有工具之间的参数传递关系，确保API调用的一致性。

## 1. 数据库分析阶段

### 1.1 分析工具链

| 工具名称 | 输入参数 | 输出字段 | 存储位置 |
|---------|---------|---------|----------|
| **extract_schema** | `database_name: str` | `database`, `tables[]`, `columns[]`, `indexes[]`, `foreign_keys[]` | `memory["db_analysis"]["schema_info"]` |
| **domain_analysis** | `memory: Dict` | `domain`, `sub_domains[]`, `key_entities[]`, `business_processes[]`, `industry_terms{}` | `memory["db_analysis"]["domain_analysis"]` |
| **field_classification** | `memory: Dict` | `classifications{}`, `field_types{}`, `summary{}` | `memory["db_analysis"]["field_classification"]` |
| **column_meaning** | `memory: Dict`, `focus_columns?: List[str]` | `column_meanings{}` | `memory["db_analysis"]["column_meanings"]` |
| **table_meaning** | `memory: Dict`, `focus_tables?: List[str]` | `table_meanings{}` | `memory["db_analysis"]["table_meanings"]` |
| **er_analysis** | `memory: Dict` | `relationships[]`, `join_paths{}`, `entities{}`, `cardinality{}` | `memory["db_analysis"]["er_analysis"]` |

### 1.2 记忆结构

分析完成后，`memory["db_analysis"]` 包含：

## 2. 问题生成阶段

### 2.1 生成工具链

| 工具名称 | 输入参数 | 输出字段 | 下一工具使用 |
|---------|---------|---------|-------------|
| **scenario_tool** | `memory: Dict`<br>`iteration: int` | `id`, `category`, `business_purpose`, `description`, `difficulty`, `tables[]`, `suggested_operations[]` | → `operation_selection` |
| **operation_selection** | `scenario: Dict`<br>`memory: Dict` | `operations[]`, `join_type`, `aggregations[]`, `filters{}`, `ordering`, `limit`, `complexity_score`, `operation_sequence[]` | → `question_generation` |
| **question_generation** | `scenario: Dict`<br>`operations: Dict`<br>`memory: Dict` | `question`, `question_type`, `key_elements{}`, `expected_columns[]`, `natural_language_hints[]` | → `sql_generation` |
| **sql_generation** | `question: str`<br>`memory: Dict` | `sql`, `dialect`, `tables_used[]`, `operations_used[]`, `has_aggregation`, `has_join`, `complexity` | → `sql_validation` |

### 2.2 参数映射

```python
# 1. scenario_tool → operation_selection
operation_selection_input = {
    "scenario": scenario_tool_output,  # 完整的场景对象
    "memory": memory
}

# 2. operation_selection → question_generation  
question_generation_input = {
    "scenario": scenario_tool_output,
    "operations": operation_selection_output,  # 完整的操作对象
    "memory": memory
}

# 3. question_generation → sql_generation
sql_generation_input = {
    "question": question_generation_output["question"],  # 只需要问题字符串
    "memory": memory
}
```

## 3. 验证执行阶段

### 3.1 验证执行工具链

| 工具名称 | 输入参数 | 输出字段 | 使用场景 |
|---------|---------|---------|----------|
| **sql_validation** | `sql: str`<br>`memory: Dict` | `valid`, `syntax_check{}`, `semantic_check{}`, `warnings[]`, `suggestions[]` | 验证SQL语法和语义 |
| **sql_execution** | `sql: str`<br>`limit?: int`<br>`timeout?: int` | `success`, `data[]`, `row_count`, `column_names[]`, `execution_time`, `affected_rows`, `error` | 执行SQL获取结果 |

### 3.2 参数映射

```python
# sql_generation → sql_validation
validation_input = {
    "sql": sql_generation_output["sql"],
    "memory": memory
}

# sql_generation → sql_execution
execution_input = {
    "sql": sql_generation_output["sql"],
    "limit": 10,  # 可选
    "timeout": 30  # 可选
}
```

## 4. 反思修正阶段

### 4.1 反思工具

| 工具名称 | 输入参数 | 输出字段 | 决策依据 |
|---------|---------|---------|----------|
| **sql_reflection** | `sql: str`<br>`execution_result: Dict`<br>`question: str`<br>`scenario: Dict`<br>`operations: Dict`<br>`memory_usage: Dict` | `needs_revision`, `quality_score`, `issues[]`, `evaluation{}`, `problem_source`, `root_cause_analysis{}`, `recommended_action{}`, `suggestions[]` | Agent决策 |
| **sequential_thinking** | `problem: List[str]`<br>`context: Dict` | `problem_step`, `problem_type`, `root_cause`, `fix_strategy{}`, `confidence` | 深度分析 |

### 4.2 反思输入构建

```python
# 构建反思输入
reflection_input = {
    "sql": sql_generation_output["sql"],
    "execution_result": sql_execution_output,  # 完整的执行结果
    "question": question_generation_output["question"],
    "scenario": scenario_tool_output,  # 完整的场景对象
    "operations": operation_selection_output,  # 完整的操作对象
    "memory_usage": memory  # 完整的记忆对象
}

# 构建深度思考输入（如果需要）
if reflection_output["needs_revision"]:
    thinking_input = {
        "problem": reflection_output["issues"],
        "context": {
            "scenario": scenario_tool_output,
            "operations": operation_selection_output,
            "question": question_generation_output,
            "sql": sql_generation_output,
            "execution": sql_execution_output,
            "reflection": reflection_output,
            "memory": memory
        }
    }
```

## 5. 关键对齐点

### 5.1 必须保持一致的参数

1. **memory 参数**
   - 所有分析工具（除extract_schema）都使用 `memory` 参数
   - 所有生成工具都使用 `memory` 参数
   - sql_validation 使用 `memory` 参数

2. **完整对象传递**
   - `scenario`：从 scenario_tool 输出后，完整传递给后续工具
   - `operations`：从 operation_selection 输出后，完整传递给后续工具
   - `execution_result`：从 sql_execution 输出后，完整传递给 sql_reflection

3. **字符串提取**
   - `question`：sql_generation 只需要 question_generation_output["question"]
   - `sql`：验证和执行工具只需要 sql_generation_output["sql"]

### 5.2 可选参数

- `focus_columns`：column_meaning_tool 的可选参数
- `focus_tables`：table_meaning_tool 的可选参数  
- `limit` 和 `timeout`：sql_execution_tool 的可选参数

### 5.3 不可修改的结果

- `scenario_tool` 的输出（预定义模板）
- `operation_selection_tool` 的输出（预定义规则）

### 5.4 可修正的结果

- 所有分析工具的输出（可重新执行并更新记忆）
- `question_generation_tool` 的输出
- `sql_generation_tool` 的输出

## 6. 错误处理

### 6.1 参数验证

每个工具都应验证输入参数的完整性：

```python
def _run(self, **kwargs):
    # 验证必需参数
    if "memory" not in kwargs:
        raise ToolParameterError(self.name, "memory", "Missing required parameter")
    
    # 验证记忆结构
    memory = kwargs["memory"]
    if "db_analysis" not in memory:
        raise ToolParameterError(self.name, "memory", "Database analysis not found in memory")
```

### 6.2 输出验证

确保输出包含所有必需字段：

```python
def _validate_output(self, output: Dict[str, Any]) -> None:
    required_fields = ["sql", "dialect", "tables_used"]
    for field in required_fields:
        if field not in output:
            raise ToolExecutionError(self.name, f"Missing required output field: {field}")
```
