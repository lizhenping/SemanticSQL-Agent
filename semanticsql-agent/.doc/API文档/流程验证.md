## 1. 数据库分析流程

### 1.1 初始化阶段

```python
# 1. 创建记忆管理器（LangChain BaseMemory）
from semanticsql_agent.utils.memory import DatabaseAnalysisMemory
memory = DatabaseAnalysisMemory()

# 2. 创建数据库管理器
from semanticsql_agent.utils.database import DatabaseManager
db_manager = DatabaseManager(db_config)

# 3. 创建 LLM 客户端（使用 LangChain ChatOpenAI）
from semanticsql_agent.utils.llm_client import LLMClient
llm_client = LLMClient(api_key="...", model="qwen-max")
llm = llm_client.get_chat_model()  # 返回 ChatOpenAI 实例
```

### 1.2 数据库分析执行

```python
# 4. 执行数据库分析（按顺序）
# 4.1 提取结构
schema_tool = SchemaExtractionTool(db_manager=db_manager)
schema_result = schema_tool.run({"database_name": "ecommerce"})
memory.update_analysis("schema_info", schema_result)

# 4.2 领域分析
domain_tool = DomainAnalysisTool(llm=llm)
domain_result = domain_tool.run({
    "memory": memory.load_memory_variables({})
})
memory.update_analysis("domain_analysis", domain_result)

# 4.3 字段分类
field_tool = FieldClassificationTool(llm=llm)
field_result = field_tool.run({
    "memory": memory.load_memory_variables({})
})
memory.update_analysis("field_classification", field_result)

# 4.4 列含义分析
column_tool = ColumnMeaningTool(llm=llm)
column_result = column_tool.run({
    "memory": memory.load_memory_variables({})
})
memory.update_analysis("column_meanings", column_result)

# 4.5 表含义分析
table_tool = TableMeaningTool(llm=llm)
table_result = table_tool.run({
    "memory": memory.load_memory_variables({})
})
memory.update_analysis("table_meanings", table_result)

# 4.6 ER 关系分析
er_tool = ERAnalysisTool(llm=llm)
er_result = er_tool.run({
    "memory": memory.load_memory_variables({})
})
memory.update_analysis("er_analysis", er_result)
```

## 2. 问题生成流程（Agent 自主执行）

### 2.1 Agent 驱动的生成流程

**重要**：以下流程不是硬编码的，而是通过 Agent 的提示词引导实现的。

```python
# 5. 创建 SQL Agent
agent = SQLAgent(
    config=Settings(),
    db_config=db_config,
    callbacks=[TrajectoryCallbackHandler()]
)

# 6. Agent 通过提示词引导执行任务
# Agent 内部会：
# - 使用 sequential_thinking 工具思考整体策略
# - 自主决定调用哪些工具
# - 根据执行结果决定是否需要反思和修正

# 执行问题生成任务
result = agent.generate_questions(
    count=100,
    output_file="training_data.jsonl"
)
```

### 2.2 Agent 的系统提示词引导

```python
# Agent 的系统提示词示例
system_prompt = """
你是一个智能 SQL 生成助手。你的任务是生成高质量的自然语言问题和对应的 SQL 查询。

## 执行策略

1. **初始分析**：
   - 首先使用 sequential_thinking 工具思考整体策略
   - 执行数据库分析（只执行一次）：
     * extract_schema - 获取数据库结构
     * domain_analysis - 识别业务领域
     * field_classification - 分类字段语义
     * column_meaning - 分析列业务含义
     * table_meaning - 分析表业务职责
     * er_analysis - 分析表关系
   - 分析结果会自动保存到记忆中

2. **问题生成循环**（根据指定数量）：
   对于每个要生成的问题：
   - 使用 scenario_tool 选择一个场景（从预定义模板，传入当前迭代次数）
   - 使用 operation_selection 为场景选择合适的 SQL 操作
   - 使用 question_generation 生成自然语言问题（使用场景、操作和记忆）
   - 使用 sql_generation 生成对应的 SQL（使用问题和记忆）
   - 使用 sql_validation 验证 SQL 语法
   - 使用 sql_execution 执行 SQL 测试
   - 使用 sql_reflection 评估结果质量

3. **智能修正**：
   如果 sql_reflection 发现需要修正：
   - 调用 sequential_thinking 深度分析问题
   - 根据分析结果，决定：
     * 如果是数据库分析有误 → 重新执行相应的分析工具并更新记忆
     * 如果是问题生成有误 → 重新执行 question_generation
     * 如果是 SQL 生成有误 → 重新执行 sql_generation
   - 继续执行后续步骤

记住：你需要自主决策，根据工具的输出结果决定下一步行动。
"""

# Agent 会根据这个提示词自主执行
```

## 3. Agent 集成方式

### 3.1 使用 LangChain Agent

```python
from semanticsql_agent.agent import SQLAgent

# 创建 Agent（内部使用 LangChain AgentExecutor）
agent = SQLAgent(
    config=Settings(),
    db_config=DatabaseConfig(...),
    callbacks=[TrajectoryCallbackHandler()]
)

# 单次查询
result = agent.query("查询2024年1月的销售总额")

# 批量生成问题
generation_result = agent.generate_questions(
    count=100,
    output_file="training_data.jsonl"
)
```

### 3.2 Agent 内部流程

```python
# SQLAgent 内部实现
class SQLAgent(BaseAgent):
    def __init__(self, ...):
        super().__init__(...)
        # 创建所有工具
        self.tools = [
            SchemaExtractionTool(...),
            DomainAnalysisTool(...),
            FieldClassificationTool(...),
            ColumnMeaningTool(...),
            TableMeaningTool(...),
            ERAnalysisTool(...),
            ScenarioTool(...),
            OperationSelectionTool(...),
            QuestionGenerationTool(...),
            SQLGenerationTool(...),
            SQLValidationTool(...),
            SQLExecutionTool(...),
            SQLReflectionTool(...),
            SequentialThinkingTool(...)
        ]
        
        # 创建 LangChain Agent
        from langchain.agents import create_react_agent, AgentExecutor
        
        self.prompt = ChatPromptTemplate.from_messages([
            SystemMessagePromptTemplate.from_template(self.get_system_prompt()),
            MessagesPlaceholder(variable_name="chat_history", optional=True),
            HumanMessagePromptTemplate.from_template("{input}"),
            MessagesPlaceholder(variable_name="agent_scratchpad")
        ])
        
        agent = create_react_agent(
            llm=self.llm,
            tools=self.tools,
            prompt=self.prompt
        )
        
        self.agent_executor = AgentExecutor(
            agent=agent,
            tools=self.tools,
            memory=self.memory,
            callbacks=self.callbacks,
            max_iterations=15,
            handle_parsing_errors=True
        )
```

## 4. LangChain 组件使用总结

### 4.1 核心组件

1. **Agent 框架**
   - `langchain.agents.create_react_agent` - 创建 ReAct 智能体
   - `langchain.agents.AgentExecutor` - 执行器
   - `langchain.agents.agent_types.AgentType` - Agent 类型

2. **工具系统**
   - `langchain.tools.BaseTool` - 所有工具的基类
   - `langchain.pydantic_v1` - 参数验证

3. **记忆系统**
   - `langchain.memory.BaseMemory` - 记忆基类
   - `langchain.memory.ConversationSummaryBufferMemory` - 对话记忆

4. **LLM 集成**
   - `langchain.chat_models.ChatOpenAI` - LLM 客户端
   - `langchain.callbacks.BaseCallbackHandler` - 回调处理

5. **提示词管理**
   - `langchain.prompts.ChatPromptTemplate` - 聊天提示词模板
   - `langchain.prompts.SystemMessagePromptTemplate` - 系统消息模板
   - `langchain.prompts.HumanMessagePromptTemplate` - 用户消息模板
   - `langchain.prompts.MessagesPlaceholder` - 消息占位符

### 4.2 简化效果

1. **工具管理**：使用 LangChain BaseTool 自动处理参数验证、错误处理、日志记录
2. **Agent 执行**：AgentExecutor 自动管理工具调用、记忆更新、执行流程
3. **提示词管理**：ChatPromptTemplate 提供结构化的提示词管理
4. **错误处理**：LangChain 提供统一的错误处理机制
5. **回调系统**：BaseCallbackHandler 提供标准的执行跟踪

## 5. 流程验证结果

✅ **数据库分析流程**：工具按顺序执行，结果保存到记忆
✅ **问题生成流程**：循环生成，每次选择一个场景
✅ **记忆传递**：所有生成工具从统一记忆获取数据
✅ **反思机制**：支持精确定位问题并重新执行
✅ **LangChain 集成**：充分利用 LangChain 组件简化代码

## 6. 改进建议

1. **统一工具参数**：所有工具都应该接收 memory 参数，而不是零散的参数
2. **自动化流程**：Agent 应该根据提示词自动执行流程，而不是硬编码
3. **更好的错误恢复**：利用 LangChain 的错误处理机制实现自动重试
