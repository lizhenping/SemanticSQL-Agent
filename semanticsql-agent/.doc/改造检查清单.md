## 六、验收标准

1. **LangChain 集成**
   - [ ] 所有工具继承自 LangChain BaseTool
   - [ ] Agent 使用 AgentExecutor
   - [ ] Memory 使用 BaseMemory

2. **参数统一**
   - [ ] 所有工具接收 memory 参数
   - [ ] 参数使用 Pydantic 验证

3. **功能正确**
   - [ ] 只支持批量生成（无单次查询）
   - [ ] 反思机制能识别问题并建议工具

4. **代码质量**
   - [ ] 无冗余文件
   - [ ] 统一的异常处理
   - [ ] 清晰的模块结构
