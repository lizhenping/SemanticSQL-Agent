# SemanticSQL Agent 命令行指令

## 系统概述
SemanticSQL Agent 是一个**基于 LangChain 的智能 SQL 训练数据生成系统**。通过 ReAct 模式，Agent 自主分析数据库、生成问题、创建 SQL、执行验证并反思优化，最终输出高质量的训练数据集。

## 系统配置

### 1. LLM 服务启动（VLLM）
```bash
# 启动 Qwen3-14B 模型服务
CUDA_VISIBLE_DEVICES=2 vllm serve /root/autodl-tmp/model/Qwen3-14B \
  --host 0.0.0.0 --port 9991 \
  --trust-remote-code --dtype auto \
  --max-model-len 32768 --max-num-seqs 256 \
  --gpu-memory-utilization 0.92 --tensor-parallel-size 1 \
  --served-model-name "Qwen3-14B"
```

### 2. 环境准备
```bash
# 激活环境
source activate alphasql

# 进入项目目录
cd /path/to/semanticsql-agent
```

## 核心执行命令

## 智能体工作流程

### Agent 执行流程（ReAct 模式）
```
用户命令: python cli.py generate -n 20 -o training_data.jsonl

Agent 完整执行过程:

📊 数据库分析阶段（一次性完成）:
1. 🤔 Thought: "需要生成20条训练数据，先完整分析数据库结构"
2. 🔧 Action: schema_extraction
3. 👁️ Observation: "提取到9个表的完整结构信息"
4. 🔧 Action: domain_analysis  
5. 👁️ Observation: "识别为政务合同管理领域"
6. 🔧 Action: field_classification
7. 👁️ Observation: "字段分类完成"
8. 🔧 Action: column_meaning_analysis
9. 👁️ Observation: "列业务含义分析完成"
10. 🔧 Action: table_meaning_analysis
11. 👁️ Observation: "表业务用途识别完成"
12. 🔧 Action: er_analysis
13. 👁️ Observation: "实体关系分析完成"

🎯 问题生成循环（执行 N 次）:
对每个问题：
14. 🔧 Action: scenario_operation_generation（获取所有场景-操作组合）
15. 🔧 Action: question_generation（生成自然语言问题）
17. 🔧 Action: sql_generation（生成对应的SQL）
18. 🔧 Action: sql_validation（验证SQL语法）
19. 🔧 Action: sql_execution（执行SQL测试）
20. 🔧 Action: sql_reflection（反思执行结果）

🔄 反思决策：
- 如果 needs_revision = false → 保存数据，继续下一个
- 如果 needs_revision = true → 根据 recommended_action 重新执行相应步骤

[循环直到生成20条高质量数据]
```

## 系统特性

### 🤖 LangChain 集成
- **Agent框架**: 基于 LangChain AgentExecutor 和 ReAct 模式
- **工具系统**: 所有工具继承自 LangChain BaseTool
- **记忆管理**: 使用 LangChain BaseMemory 管理分析结果
- **回调系统**: LangChain Callbacks 记录执行轨迹

### 🔧 工具链（14个工具）
```
├── 分析工具 (6个)
│   ├── schema_extraction: 数据库结构提取
│   ├── domain_analysis: 业务领域识别  
│   ├── field_classification: 字段语义分类
│   ├── column_meaning_analysis: 列业务含义分析
│   ├── table_meaning_analysis: 表业务含义分析
│   └── er_analysis: 实体关系分析
├── 生成工具 (3个)
│   ├── scenario_operation_generation: 场景-操作组合生成（核心工具）
│   ├── question_generation: 自然语言问题生成
│   └── sql_generation: SQL查询生成
├── 验证工具 (2个)
│   ├── sql_validation: SQL语法验证
│   └── sql_execution: SQL执行测试
├── 反思工具 (1个)
│   └── sql_reflection: 结果反思（识别问题源）
└── 思考工具 (1个)
    └── sequential_thinking: 深度分析
```

### 🔄 智能反思机制
- **问题源识别**: `problem_source` 定位问题来源
- **根因分析**: `root_cause_analysis` 深入分析原因
- **推荐行动**: `recommended_action` 建议下一步工具
- **精准修正**: 只重新执行有问题的步骤

### 📊 质量保证
- **真实执行**: 所有 SQL 在数据库中实际执行
- **语法验证**: 使用 EXPLAIN 验证 SQL 语法
- **语义匹配**: LLM 评估问题与 SQL 的匹配度
- **结果验证**: 检查执行结果的合理性
