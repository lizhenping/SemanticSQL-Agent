# SemanticSQL Agent 设计规范

## 1. 项目概述

### 1.1 项目简介
SemanticSQL Agent 是一个自然语言转SQL工具，用户输入中文问题，系统自动生成并执行SQL查询。

### 1.2 核心功能
- **自然语言理解**：理解中文查询需求
- **SQL生成**：自动生成正确的SQL语句  
- **查询执行**：连接数据库执行查询并返回结果
- **多数据库支持**：支持 MySQL、PostgreSQL、SQLite

### 1.3 使用场景
- 非技术人员查询数据库
- 快速数据统计和分析
- 数据库结构探索
- SQL学习辅助工具

## 2. 系统设计

### 2.1 基本架构
```
用户输入（中文） → Agent分析 → SQL生成 → 执行查询 → 返回结果
```

### 2.2 主要组件
1. **CLI界面**：命令行交互入口
2. **SmartSQLAgent**：核心处理逻辑
3. **工具集**：
   - 数据库连接工具
   - 模式分析工具
   - SQL生成工具
   - SQL执行工具
4. **配置管理**：YAML配置文件

### 2.3 工作流程
1. 用户通过CLI输入查询需求
2. Agent理解需求并分析数据库结构
3. 生成对应的SQL语句
4. 执行SQL并返回结果
5. 格式化输出给用户

## 3. 核心设计

### 3.1 ReAct模式
采用观察-思考-行动的循环模式：
- **观察**：理解用户需求和当前状态
- **思考**：决定下一步行动
- **行动**：调用相应工具完成任务

### 3.2 工具设计
每个工具专注单一功能：
- `connect_database`：建立数据库连接
- `analyze_schema`：分析表结构
- `generate_sql`：生成SQL语句
- `execute_sql`：执行查询

### 3.3 配置管理
使用YAML格式配置：
- 数据库连接信息
- LLM模型参数
- Agent行为设置

## 4. 使用示例

### 4.1 基本命令
```bash
# 初始化配置
python main.py init

# 执行查询
python main.py run "查询所有用户数量"

# 交互模式
python main.py interactive
```

### 4.2 典型查询
- "统计每个部门的员工数量"
- "查找最近7天的订单"
- "计算本月销售总额"

## 5. 技术选型

### 5.1 核心依赖
- Python 3.8+
- Click（CLI框架）
- SQLAlchemy（数据库操作）
- OpenAI API（LLM调用）

### 5.2 数据库支持
- MySQL 5.7+
- PostgreSQL 9.6+
- SQLite 3
